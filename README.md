# elstongun.github.io

Personal site and blog, built with [Astro](https://astro.build) and published to GitHub Pages.

- Site: https://elstongun.github.io
- New post: add a Markdown file in `src/content/blog/`
- Site copy: `src/consts.ts`

```sh
npm install
npm run dev
```

Push to `main` to deploy. In the repo, set **Settings → Pages → Source** to **GitHub Actions**.

If this repository is **private**, GitHub Pages needs GitHub Pro (or Team / Enterprise). The live site is still public. On a free account, switch the repo back to public for Pages to serve it.
