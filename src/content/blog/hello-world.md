This replaces the old GitHub Pages site. New posts are Markdown files in `src/content/blog/`.

Frontmatter needs a title, description, and date:

```md
---
title: 'A title'
description: 'One-line summary'
pubDate: 'Aug 18 2026'
---

Write in Markdown below the second `---`.
```

The filename becomes the URL: `hello-world.md` → `/blog/hello-world/`.
